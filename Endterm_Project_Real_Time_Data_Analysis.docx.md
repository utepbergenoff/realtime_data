**ENDTERM PROJECT**

*Real-Time Monitoring, Time-Series Analysis, and Stream Intelligence*

Coverage: Weeks 5–8 — Real-Time Data Visualization; Time Series Analysis and Anomaly Detection; Real-Time Machine Learning Applications; Distributed Stream Processing.

| Project Element | Requirement |
| :---- | :---- |
| Goal | Extend a streaming application into an intelligent analytics system with visualization, time-series analysis, anomaly detection, machine learning, and distributed stream-processing concepts. |
| Technologies | Python, Pandas, NumPy, Matplotlib/Plotly, scikit-learn or another justified ML library. Kafka, Spark, Flink, or a simulation may be used for distributed processing. |

# **Required Tasks**

* Create continuously updated visualizations of the incoming stream with at least two meaningful charts or dashboard views.  
* Perform time-series analysis using timestamps, rolling windows, resampling, trends, seasonality, or another justified temporal method.  
* Implement and evaluate at least one anomaly-detection method.  
* Build a real-time machine-learning component for classification, regression, forecasting, or prediction.  
* Define features using only information available at prediction time.  
* Evaluate the ML component using appropriate metrics such as F1/ROC-AUC or MAE/RMSE.  
* Demonstrate distributed stream-processing concepts using multiple workers/stages, partitioned streams, producers/consumers, or a suitable framework.  
* Measure at least two operational characteristics, such as throughput, processing latency, event count, or backlog.

# **Deliverables**

* Complete Python implementation and configuration files.  
* Dataset/data generator and reproducibility instructions.  
* Visualization or dashboard component.  
* Anomaly-detection component with evaluation results.  
* Machine-learning component with training and evaluation results.  
* Distributed stream-processing demonstration or architecture prototype.  
* Technical report of approximately 8–10 pages.  
* Short presentation and demonstration.

# **Assessment Focus**

The project should demonstrate competence in real-time visualization, time-series analysis, anomaly detection, machine learning, and distributed stream-processing concepts.
